# bowling 🎳

十瓶制保龄球计分器：输入标准记分符号，按官方规则算出总分。

## 用法

```bash
python -m bowling "X X X X X X X X X XXX"   # 完美局 -> 300
python -m bowling "9- 9- 9- 9- 9- 9- 9- 9- 9- 9-" --frames
echo "X X X X X X X X X XXX" | python -m bowling   # 管道输入也支持
```

## 记分符号

| 符号 | 含义 |
| ---- | ---- |
| `X` | 全中(strike)，一球 10 瓶 |
| `/` | 补中(spare)，两球合计 10 瓶 |
| `-` | 洗沟(gutter)，0 瓶 |
| `0-9` | 该球击倒瓶数 |

计分规则：全中奖励接下来两球，补中奖励接下来一球；第 10 格全中/补中可多投 1-2 球。

## 已知局限

- 只做计分，不做球局模拟或投球建议。
- 输入记分串必须完整合法；残局(进行中)输入可能因球数不足报错。
- 命令行参数会进入 shell 历史，敏感场合无影响(这只是游戏分数)。
